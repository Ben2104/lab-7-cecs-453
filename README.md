# Note Saver

A Flutter note app using the Code Lab 5 MVVM, repository, singleton, and SQLite structure.

Run on an Android or iOS device or simulator:

```sh
flutter pub get
flutter run
```

Tap + to add a note. Tap the pencil beside a note to edit its title and description, then save. Notes are stored locally in SQLite and reload when the app starts.

Run checks with `flutter analyze` and `flutter test`.
